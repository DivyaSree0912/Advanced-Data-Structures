# Advanced Data Structures in C

This repository contains C programs implementing various data structures and algorithms as part of my Advanced Data Structures coursework.

The programs cover arrays, linked lists, stacks, queues, trees, searching, sorting, graph traversal, and priority queues.

## 📚 Topics Covered

### 1. Arrays
- Array Operations

### 2. Linked Lists
- Singly Linked List (SLL)

### 3. Stacks
- Stack Using Arrays
- Stack Using Linked List
- Double-Ended Stack
- Min-Max Stack
- Undo and Redo Operations Using Stack

### 4. Queues
- Queue Using Arrays
- Queue Using Linked List
- Circular Queue
- Double-Ended Queue (Deque)

### 5. Priority Queues
- Priority Queue Using Two Arrays
- Priority Queue Using Linked List
- Priority Queue Using Heap

### 6. Trees
- Binary Search Tree (BST)
- Finding Minimum and Maximum Elements in a BST

### 7. Graph Algorithms
- Breadth-First Search (BFS) Using Adjacency Matrix
- Depth-First Search (DFS) Using Adjacency Matrix

### 8. Searching Algorithms
- Binary Search
- Interpolation Search

### 9. Sorting Algorithms
- Merge Sort
- Quick Sort
- Radix Sort

## 🛠️ Technologies Used

- **Programming Language:** C
- **Compiler:** GCC
- **Development Environment:** Visual Studio Code


## 🎯 Purpose

The purpose of this repository is to practice and understand data structures and algorithms through C programming, including their implementation and operations.
